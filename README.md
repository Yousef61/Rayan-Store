# 🛍️ Rayan Store: متجر أونلاين

موقع متجر لـ **Rayan Store** (شنط مدارس، شنط حضانة، طرح، بندانات). الزباين بيشتروا منه مباشرة بدل رسائل الفيسبوك.

## المميزات

**للزبون**
- واجهة عربية بالكامل وشكلها مظبوط على الموبايل
- أقسام وبحث وصفحة لكل منتج فيها صور وألوان أو موديلات وكمية
- سلة مشتريات، وطلب بالدفع عند الاستلام (الاسم، الموبايل، المحافظة، العنوان)
- زرار واتساب للسؤال عن أي منتج أو لتأكيد الطلب بعد ما يخلص

**ليكِ أنتِ (لوحة التحكم على `/admin`)**
- إضافة وتعديل المنتجات: صور كتير، سعر وسعر قبل الخصم، الكمية، الألوان، منتج مميز، إخفاء المنتج
- استلام الطلبات ومتابعة حالتها: جديد ← تم التأكيد ← تم الشحن ← تم التسليم، أو ملغي (الإلغاء بيرجّع الكمية للمخزون)
- المخزون بيقل لوحده مع كل طلب، والزبون مش هيقدر يطلب أكتر من الكمية المتاحة
- إحصائيات سريعة: الطلبات الجديدة، طلبات النهارده، المبيعات
- الإعدادات: رقم الواتساب، مصاريف الشحن، شحن مجاني فوق مبلغ معين، شريط الإعلان، رابط الفيسبوك، كلمة السر

## التشغيل على جهازك

محتاج [Node.js](https://nodejs.org) إصدار 22.13 أو أحدث.

```bash
npm install
npm start
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin (كلمة السر الافتراضية `rayan123`، **غيّريها فوراً** من الإعدادات)

## متغيرات البيئة (اختيارية)

| المتغير | الاستخدام |
|---|---|
| `PORT` | البورت (الافتراضي 3000) |
| `ADMIN_PASSWORD` | كلمة سر الأدمن أول مرة يتشغل فيها الموقع |
| `DATA_DIR` | مكان قاعدة البيانات (الافتراضي `data/`) |
| `UPLOAD_DIR` | مكان صور المنتجات (الافتراضي `uploads/`) |

## الرفع على الإنترنت

الموقع بيحفظ البيانات (SQLite) والصور على الهارد، فلازم الاستضافة يكون فيها **تخزين دائم** (Volume).
- **Railway / Render / Fly.io**: اربطي الريبو، الـ `Dockerfile` جاهز. اعملي Volume على المسار `/data` وحطي `ADMIN_PASSWORD`.
- **سيرفر VPS**: `npm install && npm start` (ويفضل مع `pm2`) وقدامه Nginx وشهادة HTTPS.

بعد الرفع حطي رابط الموقع على صفحة الفيسبوك وفي زرار "تسوق الآن".

**النسخ الاحتياطي:** خدي نسخة من مجلد `data/` ومجلد `uploads/` كل فترة.

## هيكل المشروع

```
server.js          السيرفر وكل الـ API
src/db.js          قاعدة البيانات والإعدادات
src/auth.js        تسجيل دخول الأدمن
public/            واجهة المتجر (HTML/CSS/JS)
public/admin/      لوحة التحكم
```
